lalalazy

A collection of Final Fantasy XIV Dalamud plugins that automate the tedious bits — for very lazy players.

Add the repo Browse plugins
Custom Dalamud repository
https://raw.githubusercontent.com/dajoey/lalalazy/main/pluginmaster.json
1. In-game, type /xlsettings → Experimental tab.
2. Paste the URL into Custom Plugin Repositories and hit +.
3. Save, then find the plugins in /xlplugins.
