LazyCrucible

Original Testing Config window

Your familiars, picked for every Crucible fight.

Run roster, filled
Open the entry menu at Bentbranch Meadows and the ten-familiar run roster fills itself with the familiars that cover the board best.
Battlehorn picks per fight
Before every fight in the Crucible of the Unbroken, the three Battlehorn slots get the familiars best suited to that fight’s mechanics — weakness element, interrupts, crowd control and dispels. Knocked-out and badly hurt familiars stay on the bench.
You stay in charge
Every pick is announced in chat, every automation has its own toggle, and your manual edits always win.
Beast-pick advisor
A panel that lays out the picks for each battle on any board.
Screen recorder
A read-only recorder logs every Crucible screen to the Dalamud log, laying the groundwork for automating the rest: path choice, spoils, treasure, shop and feeding, campsite and beast gear.

Install — add the repo, then grab LazyCrucible
https://raw.githubusercontent.com/dajoey/lalalazy/main/pluginmaster.json
1. /xlsettings → Experimental → paste under Custom Plugin Repositories.
2. Save, open /xlplugins, search LazyCrucible. Testing builds need the per-plugin testing opt-in.
3. Install — done.
