Lazy Retainer Live

Original Testing Config window

Real-time retainer venture countdowns for your dashboard.

Live venture countdowns
Reads the in-game retainer table every second — the same data AutoRetainer’s own timers come from — instead of the config file that only saves at AutoRetainer’s leisure.
Dashboard-ready JSON
Serves the exact frame shape the ffxiv dashboard relay already speaks, on loopback only. Once you have logged in it keeps serving that character’s last known state, so the dashboard never flickers back to stale file data mid-session.
Read-only companion
Never writes, assigns, or collects anything. AutoRetainer stays the boss of your retainers; this plugin just lets your dashboard see what it sees.
