Lazy Gear Collector

Original Active Config window

Stop doing gear bookkeeping in your head.

Every role, every slot
Occult Crescent North Horn’s Phantom Vision sets — 7 roles, 5 slots, 4 tiers — with per-role progress and click-through detail.
Prices from the game itself
Reads the shop tables at runtime, so obol and fixative costs are the game’s own numbers and survive patches.
Spots free trade-ups
Flags Arcanaut’s gear you can exchange straight in, including the two-step route that saves 4,000 obols a piece.

Install — add the repo, then grab Lazy Gear Collector
https://raw.githubusercontent.com/dajoey/lalalazy/main/pluginmaster.json
1. /xlsettings → Experimental → paste under Custom Plugin Repositories.
2. Save, open /xlplugins, search Lazy Gear Collector.
3. Install — done.
