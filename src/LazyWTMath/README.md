# Lazy WT Math — Wondrous Tails Probability Calculator

An advanced mathematical helper for Wondrous Tails in Final Fantasy XIV. Lazy WT Math displays real-time line probabilities directly onto your in-game journal interface and computes shuffle expected values, helping you secure 1, 2, and 3-line completions with precision.

---

## 🌟 Core Features

* **Real-time Probability Overlay:** Displays the exact percentage chance of obtaining 1-line, 2-line, and 3-line configurations for your current sticker placement.
* **Shuffle Average Calculator:** Calculates the expected mathematical values of what shuffling your current stickers would produce, helping you make smart, numbers-based choices.
* **Unmanaged Pointer Detours:** Employs advanced unmanaged memory detours via KamiToolKit to draw directly on top of the native FFXIV Wondrous Tails UI, resulting in a lag-free, integrated UI experience.

---

## 🚀 Installation

Add the custom plugin repository URL to your Dalamud settings:

```text
https://raw.githubusercontent.com/dajoey/lalalazy/main/pluginmaster.json
```

1. In-game, type `/xlsettings` in chat to open Dalamud Settings.
2. Select the **Experimental** tab.
3. Scroll to **Custom Plugin Repositories**, paste the repository URL into the empty field, and click **+**.
4. Click **Save and Close** (bottom-right).
5. Open `/xlplugins` in chat, search for **Lazy WT Math** in the **Available Plugins** tab, and click **Install**.
